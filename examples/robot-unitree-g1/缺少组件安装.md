# RoboNX 项目依赖安装指南

## 📦 一、安装 Livox SDK2（用于 mid360_lidar）

### 1.1 安装编译依赖

```bash
sudo apt install cmake -y
```

### 1.2 下载并编译 Livox SDK2

```bash
# 克隆 SDK2 仓库
git clone https://github.com/Livox-SDK/Livox-SDK2.git
cd Livox-SDK2

# 创建并进入编译目录
mkdir build && cd build

# 编译
cmake .. && make -j

# 安装到系统目录
sudo make install
```

### 1.3 验证安装

```bash
find /usr/local/lib -name "liblivox_lidar_sdk_shared.so*"
```

如果找到文件，说明安装成功。

## 📷 二、安装 RealSense SDK 2.0（用于 realsense_camera）

### 2.1 安装编译依赖

```bash
sudo apt update
sudo apt install -y git cmake build-essential \
    libssl-dev libusb-1.0-0-dev pkg-config \
    libgtk-3-dev libglfw3-dev libgl1-mesa-dev \
    libx11-dev libxrandr-dev libxinerama-dev \
    libxcursor-dev libxi-dev \
    udev
```

### 2.2 克隆并切换到指定版本

```bash
cd ~/robonix/examples/robot-unitree-g1

# 如果已存在，先删除旧的
rm -rf librealsense

git clone https://github.com/IntelRealSense/librealsense.git
cd librealsense

# 切换到 v2.55.1（与构建脚本要求的版本一致）
git checkout v2.55.1

# 如果 v2.55.1 不存在，查看可用版本：
# git tag | grep v2
```

### 2.3 配置和编译

```bash
mkdir -p build && cd build

cmake .. \
    -DCMAKE_BUILD_TYPE=Release \
    -DBUILD_EXAMPLES=true \
    -DBUILD_GRAPHICAL_EXAMPLES=true \
    -DBUILD_UNIT_TESTS=false \
    -DBUILD_PYTHON_BINDINGS=false \
    -DFORCE_RSUSB_BACKEND=false \
    -DCMAKE_INSTALL_PREFIX=/usr/local

make -j$(nproc)
sudo make install
```

> ⚠️ **注意**：这里 `BUILD_EXAMPLES` 和 `BUILD_GRAPHICAL_EXAMPLES` 都设为 `true`，这样才能生成 `realsense-viewer` 图形工具。

### 2.4 配置 udev 规则

```bash
cd ..

# 复制 udev 规则文件
sudo cp config/99-realsense-libusb.rules /etc/udev/rules.d/
sudo cp config/99-realsense-d4xx-mipi-dfu.rules /etc/udev/rules.d/ 2>/dev/null || true

# 重新加载 udev 规则
sudo udevadm control --reload-rules
sudo udevadm trigger

# 将当前用户添加到 plugdev 组
sudo usermod -a -G plugdev $USER
```

### 2.5 更新动态链接库缓存

```bash
sudo ldconfig

# 设置环境变量（永久生效）
echo 'export LD_LIBRARY_PATH=/usr/local/lib:$LD_LIBRARY_PATH' >> ~/.bashrc
echo 'export PATH=/usr/local/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

### 2.6 验证安装

```bash
# 检查版本
pkg-config --modversion librealsense2

# 检查库文件
ls -la /usr/local/lib/librealsense2.so*

# 检查 realsense-viewer
ls -la /usr/local/bin/realsense-viewer

# 如果找不到，创建软链接
sudo ln -s /usr/local/bin/realsense-viewer /usr/bin/realsense-viewer 2>/dev/null || true
```

## 🔌 三、硬件连接检查

### 3.1 检查 RealSense 相机

```bash
# 插入 RealSense 相机后检查
lsusb | grep -i intel
lsusb | grep -i realsense

# 检查视频设备
ls -la /dev/video*

# 运行测试（需要图形界面）
realsense-viewer

# 或使用命令行测试
rs-enumerate-devices
```

### 3.2 检查 Unitree G1 机器人连接

```bash
# G1 默认 IP（根据实际情况调整）
ping -c 3 192.168.123.161

# 检查网络接口
ifconfig
# 或
ip addr

# 设置环境变量（如果已连接）
export UNITREE_SDK_IP=192.168.123.161
```

## 📋 五、快速状态检查脚本

将以下命令保存为 `check_status.sh` 并运行，可以快速诊断环境状态：

```bash
#!/bin/bash
echo "========================================="
echo "  RoboNX 环境状态检查"
echo "========================================="

echo ""
echo "【Livox SDK】"
find /usr/local/lib -name "liblivox_lidar_sdk_shared.so*" 2>/dev/null && echo "  ✅ Livox SDK 已安装" || echo "  ❌ Livox SDK 未安装"

echo ""
echo "【RealSense SDK】"
pkg-config --modversion librealsense2 2>/dev/null && echo "  ✅ RealSense SDK 已安装" || echo "  ❌ RealSense SDK 未安装"

echo ""
echo "【realsense-viewer】"
which realsense-viewer 2>/dev/null && echo "  ✅ realsense-viewer 在 PATH 中" || echo "  ❌ realsense-viewer 不在 PATH"

echo ""
echo "【RealSense 相机】"
lsusb | grep -iE "intel|realsense" && echo "  ✅ RealSense 相机已连接" || echo "  ❌ RealSense 相机未连接"

echo ""
echo "【Unitree G1 机器人】"
ping -c 1 -W 1 192.168.123.161 2>/dev/null && echo "  ✅ G1 机器人可达 (192.168.123.161)" || echo "  ⚠️  G1 机器人不可达 (192.168.123.161)"
echo ""
```

运行：

```bash
chmod +x check_status.sh
./check_status.sh
```

## ⚠️ 常见问题

| 问题 | 解决方案 |
|------|----------|
| `realsense-viewer` 找不到 | 重新编译时设置 `-DBUILD_GRAPHICAL_EXAMPLES=true` |
| `liblivox_lidar_sdk_shared.so` 找不到 | 检查 Livox SDK2 是否安装到 `/usr/local/lib` |
| `g1_chassis` 启动失败 | 确认 G1 机器人已连接且网络通畅 |
| `realsense_camera` 启动失败 | 确认 RealSense 相机已插入 USB 3.0 端口 |
| 权限不足 | 重新插拔设备，或执行 `sudo udevadm trigger` |
